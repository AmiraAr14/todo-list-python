# 📝 To-Do List

Une application simple de gestion de tâches réalisée avec Python.

## ✨ Fonctionnalités

- Ajouter une tâche
- Afficher les tâches
- Supprimer une tâche
- Quitter l'application

## 🛠️ Technologies utilisées

- Python

## ▶️ Lancer le projet

Installer Python, puis exécuter :

```bash
python interface.py
```

Avec ce projet, j'ai appris à utiliser :

Les listes
Les fonctions
Les boucles while et for
Les conditions if
append()
del
Les entrées utilisateur avec input()
